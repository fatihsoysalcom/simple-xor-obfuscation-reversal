# Simple XOR Obfuscation Reversal

This example demonstrates a basic form of data obfuscation using XOR encryption and its reversal. It simulates how a reverse engineer might uncover hidden data or logic by analyzing an obfuscated string and identifying its decryption routine and key.

## Language

`python`

## How to Run

Save the code as main.py.
Run from your terminal: python main.py
